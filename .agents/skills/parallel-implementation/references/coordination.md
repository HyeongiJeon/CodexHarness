# Coordination contract

Use parallel work only when the task, project rules, and available collaboration tools authorize it. Share the requirement, acceptance evidence, stable interface, writable paths, dependency order, deadline, and return format. Give each writer disjoint ownership; reserve shared manifests, lockfiles, and integration entrypoints for one owner. Integrate early, inspect actual diffs, preserve others' changes, and validate the combined result. If delegation is unavailable or unauthorized, proceed sequentially.
