# Time Budget Management

Original project and exam instructions take precedence over this workflow.
Exam profile: no Astra, computer-use, push, external uploads, or AI-prohibited written answers.

**Inputs:** Actual start/deadline/timezone, remaining minutes, required outcomes, setup risks.

For the default budget; adapt immediately to actual elapsed time, read [references/180-minute-plan.md](references/180-minute-plan.md).

## Procedure

1. Compute remaining wall-clock time from a real clock; set feature cutoff and protected verification/delivery reserves based on risk.
2. Prove the environment and highest-risk requirement early. Reach a runnable slice before exhaustive planning.
3. At meaningful milestones compare remaining time with mandatory work; reorder optional tasks before consuming the reserve.
4. At cutoff stabilize the main path, run checks, and package evidence. Make only fixes fitting remaining time.

**Output contract:** Short time allocation, progress-based checkpoint updates, current cutoff, and deferred optional work.

**Tools:** Reliable clock, task list, project checks, harness timer if present; never invent elapsed time.

**Verification:** Allocation fits remaining time; mandatory work has owners/sequence; verification and handoff retain executable time.

**Failure handling:** When setup overruns, select a task-compatible fallback early; record unmet requirements instead of spending the reserve blindly.
