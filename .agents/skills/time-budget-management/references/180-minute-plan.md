# 180-minute starting allocation

Treat this as a starting schedule and recalculate from the actual clock and task risk.

- 0–15 min: inspect instructions, run the project, extract acceptance criteria, identify setup risk.
- 15–30 min: prove that dependency and settle the smallest interface plan.
- 30–125 min: implement one runnable slice, then required behavior in priority order.
- 125–155 min: stabilize and cover acceptance paths with targeted checks.
- 155–175 min: verify final state, launch instructions, and artifacts.
- 175–180 min: record evidence, limits, and handoff.

Move time toward setup when environment risk is high; protect verification and handoff. Set feature cutoff earlier when acceptance or integration risk is large. Do not assume this schedule fits without checking remaining work.
