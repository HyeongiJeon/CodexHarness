# Format-specific checks

Use only the subsection for the requested format.

## PDF
Check page count, searchable text versus scans, dimensions, and reading order. Reopen and inspect changed pages plus representative unchanged pages in a local viewer. Text extraction does not prove layout fidelity.

## DOCX
Preserve styles, headings, tables, headers/footers, comments, and tracked changes when required. Reopen and inspect structure; render locally when page layout matters.

## Spreadsheet
Preserve formulas, types, named ranges, sheet names, and number formats. Reopen and inspect formulas and representative calculated values; do not replace formulas with displayed values unless requested.

## Presentation
Preserve slide order, dimensions, masters, notes, and editable objects where required. Reopen and inspect changed slides for overflow or layout shifts.

## Scans and OCR
Keep the source, mark uncertain OCR, and compare extracted text with affected image locations. Do not treat uncertain recognition as verified content.
