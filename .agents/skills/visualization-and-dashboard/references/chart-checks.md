# Chart and metric checks

Define metric formula, row grain, denominator, units, timezone, missing-data treatment, and filters before chart selection. Choose a chart that directly answers the comparison; label axes and series and avoid misleading scales. Reconcile plotted values and totals to source rows or an independent calculation. Check filters, summaries, and tables use the same data; ensure empty/error states and exports retain units and labels. Inspect a local render manually; do not automate browser or GUI interaction.
