# 개발 검증 기록

명령을 실행하기 전 결과를 채우지 않는다. 생략·실패·미확인은 그대로 표시한다. 원시 증거는 필요한 최소 로컬 경로로 연결하며 비밀·개인정보·세션 전문을 공개 커밋하지 않는다.

| 항목 | 내용 |
| --- | --- |
| 수용 기준 ID·검사자·시각 | |
| 검사한 코드 상태·변경 경로 | commit 또는 로컬 diff 식별 |
| 작업 디렉터리·환경 | |
| 정확한 명령 또는 수동 절차 | |
| 기대 결과 | |
| 실제 결과·종료 코드 | 미실행 / 통과 / 실패 / 미확인 |
| 로컬 증거 경로 | |
| 범위·한계·후속 검사 | |

모델·위임 검증이 관련되면 요청한 역할·모델·강도와 실제 관찰한 역할·모델·강도를 구분한다. 사용한 도구 API, 새 문맥 여부, 실제 자식 생성·병렬 관찰, 상속·순차 fallback을 근거와 함께 적는다. 메타데이터나 증거가 없으면 추측하지 않는다. HTTP 검사만으로 화면 검사를 통과 처리하지 않는다.
