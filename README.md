# Codex Harness · SK hynix AI Hackathon

180분 개발 과제를 위한 Codex 전문 에이전트 팀, 조건별 Skill, 로컬 검증 도구입니다. 기존 과제의 코드와 요구사항을 우선하며, 연습용 예제를 실제 시험 제출물로 대체하지 않습니다.

구축 및 검증 중입니다. 최종 사용법과 측정 결과는 검증 완료 후 이 문서와 `docs/`에 기록합니다.

시험에서는 제공된 Codex만 사용하고 업데이트, Git Push, 외부 업로드, Computer Use 자동 조작을 하지 않습니다. Astra는 사용하지 않습니다.
